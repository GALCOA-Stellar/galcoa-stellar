# 0011 — Licencia Apache-2.0


**Decisión.** El código se publica bajo Apache-2.0 ([`LICENSE`](../../LICENSE)), para que cualquiera pueda probarlo, reutilizarlo y proponer mejoras.

**Por qué.** Es la licencia habitual del ecosistema de Stellar y de Soroban, permite uso comercial, incluye una concesión expresa de patentes y pide conservar el aviso de autoría. Un proyecto que dice ser una capa de verificación para quienes construyen en Stellar necesita que se pueda usar.

**Qué no cambia.** Las reglas de demostración siguen siendo de demostración, el prototipo sigue siendo solo Testnet, y la licencia no implica aval de la Stellar Development Foundation. Las marcas y logos de GALCOA+ no se licencian con el código.
