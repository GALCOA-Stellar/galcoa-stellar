# Evidencia

Material que respalda las afirmaciones del proyecto, siempre de Testnet.

- [`TABLA-EVIDENCIA.md`](TABLA-EVIDENCIA.md): cada afirmación con su prueba, link y límite.
- `EVIDENCIA-8435d44b.md` y `.json`: corrida vigente con los links a las transacciones; `lotes-8435d44b.json` tiene las huellas.
- `ENTREVISTAS-RESUMEN.md`: resumen anonimizado de entrevistas.
- Corridas anteriores (`2e86145d`): historial de los despliegues obsoletos.

Cada pieza de evidencia debe decir qué afirma, de qué entorno sale, a qué contrato o flujo se refiere y cuándo se capturó. La evidencia respalda, no reemplaza, la fuente de verdad: el estado de los contratos y sus eventos.
